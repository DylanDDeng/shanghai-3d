## Prohibited sources (never used, never scraped)

Google Maps / Google Earth imagery and 3D models · Baidu Maps tiles / data (BD-09) · Amap/Gaode tiles / data
(GCJ-02) · Apple Maps imagery · any commercial 3D model without an explicit license · any tile server whose terms
forbid caching or use in this application.

## Final data plan

| Concern                                              | Phase 1 (current)                                                                  | Phase 2                                                               |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Building footprints                                  | OSM via Overpass, inner Shanghai (30 grid cells)                                   | Geofabrik PBF for the whole municipality; Overture buildings          |
| Building heights                                     | OSM `height` / `building:levels`; typed + area estimates otherwise (90% estimated) | Overture / CNBH-10m enrichment; roof shapes from `roof:shape`         |
| Terrain                                              | WGS84 ellipsoid                                                                    | Copernicus GLO-30 quantized-mesh (pipeline ready)                     |
| Basemap                                              | NASA GIBS (keyless) fading into the dark vector ground below 25 km                 | optional keyed imagery (`custom`, `ion-bing`)                         |
| Roads / water / parks / districts / boundary / metro | OSM                                                                                | OSM + real-time traffic feed (TBD)                                    |
| Landmarks                                            | procedural CC0 models                                                              | licensed high-fidelity or photogrammetry assets, drop-in via registry |

## Coordinate systems

Internal CRS is WGS84 (EPSG:4326 / ECEF for Cesium). OSM and Copernicus are WGS84. Anything from Chinese web
map platforms (Amap, Baidu, DataV) is GCJ-02 or BD-09 and is not ingested; `src/geo/coordinates.ts` has
`gcj02ToWgs84` only as a compatibility helper. Lesson learned: even hand-typed "well-known" Shanghai coordinates
are frequently GCJ-02 — resolve positions from OSM (`scripts/validate-data/lookup-places.ts`) and let
`npm run data:validate` reject anything outside the municipality.
